Die Konsole: erste Schritte

Montagmorgen in der Informatik der Gemeinde Wolkenried. Lea bekommt ihren ersten Auftrag: «Halte für die Inventarliste fest, welche PowerShell auf deinem Rechner läuft und was in deinem Benutzerordner liegt.» Dafür öffnet sie zum ersten Mal eine Konsole. Hier lernst du, was eine Shell ist, wie du einen Befehl eintippst und wie du mit Tab und Pfeiltasten schneller wirst.

Danach kannst du:
  • erklären, was Shell, Terminal, Prompt und Cmdlet sind.
  • PowerShell 7 (pwsh) von Windows PowerShell 5.1 (powershell.exe) unterscheiden und die Version mit $PSVersionTable prüfen.
  • den Prompt lesen und deine ersten Befehle ausführen: Get-Date, Get-Location, Get-ChildItem.
  • mit Tab, ↑, Get-History, Clear-Host und Ctrl+C umgehen.
  • entscheiden, wann du «Als Administrator ausführen» brauchst und wann nicht.

Schritt 0 · Ohne Vorwissen

Vier Wörter für den Anfang

Stell dir ein Restaurant vor. Du schreibst deine Bestellung auf einen Zettel und gibst ihn der Kellnerin. Sie bringt den Zettel in die Küche und kommt mit dem Essen zurück. Du musst nicht wissen, wie die Küche arbeitet. Du musst nur die Bestellung so schreiben, dass sie verstanden wird. Genau so arbeitest du mit PowerShell.

Shell = Kellnerinpwsh

Ein Programm, das deine getippten Befehle entgegennimmt, ausführen lässt und dir das Ergebnis zeigt. PowerShell ist eine Shell.

Terminal = ThekeWindows Terminal

Das Fenster, in dem du tippst und liest. Darin läuft eine Shell. Ein Terminal kann mehrere Shells in Tabs zeigen.

Prompt = «Was darf's sein?»PS C:\Users\lea>

Die Zeile, mit der die Shell sagt: «Ich bin bereit.» Sie zeigt auch, in welchem Ordner du gerade bist.

Cmdlet = Gericht auf der KarteGet-Date

Ein Befehl von PowerShell. Er heisst immer Verb-Nomen: Get (holen) und Date (Datum). Sprich «Kommandlet».

Kurz üben: Was ist was?

Ordne jedes Stück dem passenden Wort zu.

Schritt 1 · Tippen statt klicken

Was eine Shell kann, was die Maus nicht kann

Im Explorer klickst du dich durch Ordner. Das ist bequem, solange es um eine Datei geht. In der Informatik geht es aber oft um hundert Dateien, um zwanzig Rechner oder um eine Aufgabe, die jeden Montag wiederkommt. Dann ist Tippen stärker als Klicken:

  • Wiederholbar: Ein Befehl macht jedes Mal genau dasselbe. Du kannst ihn aufschreiben und weitergeben.
  • Automatisierbar: Viele Befehle hintereinander werden zu einem Skript, das von selbst läuft (Station 11).
  • Genau: Ein Befehl sagt dir das Ergebnis schwarz auf weiss. Du musst nicht suchen, wo du klicken müsstest.

PowerShell ist mehr als eine Shell. Microsoft beschreibt sie als Lösung für die Automatisierung aus drei Teilen: Shell, Skriptsprache und ein System für Konfigurationen. Eine Besonderheit merkst du dir schon jetzt: Die meisten Shells liefern nur Text. PowerShell liefert Objekte, also Datensätze mit Feldern wie Name, Grösse und Datum. Was das bringt, siehst du in Station 06.

Das Fenster: Windows Terminal

Das Programm, in dem du tippst, heisst Terminal. Unter Windows 11 nimmst du dafür meist Windows Terminal. Es zeigt mehrere Shells in Tabs nebeneinander: PowerShell 7, Windows PowerShell, die alte Eingabeaufforderung cmd oder eine Linux-Shell. Fehlt es auf deinem Rechner, gibt es Windows Terminal gratis im Microsoft Store.

So öffnest du PowerShell 7: Starttaste drücken, PowerShell 7 tippen, Enter. Oder Windows Terminal öffnen und im Pfeil neben dem Plus-Tab das Profil «PowerShell» wählen. Ist PowerShell 7 installiert, startest du sie aus jeder Shell auch mit dem Befehl pwsh.
Schritt 2 · pwsh und powershell.exe

Zwei PowerShells auf einem Rechner

Auf Leas Rechner gibt es zwei PowerShells. Das verwirrt am Anfang fast alle. Windows PowerShell 5.1 ist ein Teil von Windows, seit 2016 (Windows 10 und Windows Server 2016) fest eingebaut. PowerShell 7 ist die neue Generation. Du installierst sie zusätzlich, und sie läuft neben 5.1, ohne sie zu ersetzen. Neue Funktionen kommen nur noch in PowerShell 7. Dieser Lernpfad arbeitet mit PowerShell 7.

Welche PowerShell läuft gerade?

Das verrät dir die Variable $PSVersionTable. Eine Variable ist ein beschrifteter Behälter für einen Wert. Ihr Name beginnt mit $. Diese hier füllt PowerShell beim Start selbst. Tippst du nur ihren Namen und drückst Enter, zeigt PowerShell den Inhalt:


    
Wichtig sind die ersten zwei Zeilen: PSVersion 7.6.1 ist die Version, PSEdition Core heisst PowerShell 7. Dieselbe Eingabe in Windows PowerShell 5.1 auf einem Testrechner:

    
PS C:\Users\lea> $PSVersionTable

Name                           Value
----                           -----
PSVersion                      5.1.28000.3231
PSEdition                      Desktop
PSCompatibleVersions           {1.0, 2.0, 3.0, 4.0...}
BuildVersion                   10.0.28000.3231
CLRVersion                     4.0.30319.42000
WSManStackVersion              3.0
PSRemotingProtocolVersion      2.3
SerializationVersion           1.1.0.1

    
Hier steht Desktop: Das ist Windows PowerShell 5.1. Willst du nur einen einzelnen Wert, hängst du seinen Namen mit einem Punkt an. Wie das genau funktioniert, lernst du in Station 06.

    

    
Der Prompt sieht gleich aus. Beide PowerShells zeigen PS C:\Users\lea>. Am Prompt erkennst du die Version also nicht. Im Zweifel fragst du $PSVersionTable. Auch Windows Terminal hilft: Dort heisst das Profil für Version 7 «PowerShell» und das für 5.1 «Windows PowerShell».

  


  
  

    Schritt 3 · Prompt, Befehl, Enter
    
Dein erster Befehl, Schritt für Schritt

    
Lea will wissen, welches Datum der Rechner kennt. Klick dich mit «Weiter» durch. Fahre über ein unterstrichenes Satzstück oder tippe darauf: Der passende Teil leuchtet auf.

    


    
Gross oder klein? Egal.

    
PowerShell unterscheidet bei Befehlsnamen nicht zwischen Gross- und Kleinbuchstaben. get-date, GET-DATE und Get-Date sind derselbe Befehl:

    

    
Schreib trotzdem so wie Microsoft: jedes Wort mit grossem Anfangsbuchstaben. Dann liest du deine Befehle später leichter.


    
Wo bin ich? Was liegt hier?

    
Zwei weitere Befehle brauchst du ab jetzt täglich. Get-Location zeigt den Ordner, in dem du gerade arbeitest. Fachwort: aktueller Ort. Es ist derselbe Pfad, den auch der Prompt zeigt.

    

    
Get-ChildItem zeigt, was in diesem Ordner liegt. Child Item heisst «Kind-Element»: die Einträge im Ordner. Das d in der Spalte Mode steht für directory, also Ordner.

    

    
Schreibst du einen Ordnernamen dahinter, zeigt Get-ChildItem dessen Inhalt, zum Beispiel Get-ChildItem Dokumente. Mehr dazu in Station 04.


    
Wenn PowerShell einen Befehl nicht kennt

    
Ein Tippfehler, und PowerShell antwortet rot:

    

    
Auf Deutsch: «Der Begriff ‹GetDate› ist nicht bekannt als Name eines Cmdlets, einer Funktion, einer Skriptdatei oder eines Programms. Prüfe die Schreibweise.» Hier fehlt der Bindestrich. Keine Sorge: Ein Fehler macht nichts kaputt. Du liest die Meldung, korrigierst und versuchst es nochmals. Fehlermeldungen von PowerShell 7 sind englisch, auch auf einem deutschen Windows.

  


  
  

    Schritt 4 · Weniger tippen, mehr erreichen
    
Tab, Pfeiltasten, Verlauf und Abbrechen

    
Profis tippen nicht schneller, sie tippen weniger. Die Bearbeitung der Eingabezeile übernimmt in PowerShell ein Modul namens PSReadLine. Es färbt deine Eingabe ein, merkt sich frühere Befehle und ergänzt Namen.


    
Tab: PowerShell schreibt fertig

    
Tippe den Anfang eines Namens und drück Tab. Aus Get-Chi wird Get-ChildItem. Das klappt auch für Ordner: Get-ChildItem Do und Tab ergibt Get-ChildItem .\Dokumente. Passen mehrere Namen, zeigt jedes weitere Tab den nächsten Treffer (hier .\Downloads), Shift+Tab geht zurück. Der Vorsatz .\ heisst «im aktuellen Ordner».

    
Tab ist auch eine Rechtschreibprüfung. Ergänzt Tab nichts, gibt es keinen Namen mit diesem Anfang. Dann hast du dich vertippt, bevor du Enter drückst.


    
Pfeiltasten und Verlauf

    
Mit ↑ holst du den letzten Befehl zurück in die Eingabezeile, mit jedem weiteren ↑ den davor, mit ↓ wieder vorwärts. Du kannst ihn ändern und mit Enter erneut ausführen. Den Verlauf als Liste zeigt Get-History:

    
PS C:\Users\lea> Get-History

  Id     Duration CommandLine
  --     -------- -----------
   1        0.032 Get-Date
   2        0.013 Get-Location
   3        0.021 Get-ChildItem

    
Id ist die laufende Nummer, Duration die Laufzeit in Sekunden, CommandLine der Befehl, so wie du ihn getippt hast. Ein Befehl kommt erst in den Verlauf, wenn er fertig ist. Darum fehlt Get-History selbst in dieser Liste.

    
Zwei Gedächtnisse. Get-History kennt nur die aktuelle Sitzung. Schliesst du das Fenster, ist diese Liste weg. PSReadLine speichert deine Eingaben zusätzlich in einer Datei. Darum holt ↑ in einem neuen Fenster auch Befehle von gestern zurück, Get-History aber nicht.


    
Bildschirm leeren und abbrechen

    
Clear-Host (kurz cls) leert das Fenster. Der Verlauf bleibt dabei erhalten, ↑ und Get-History funktionieren weiter. Läuft ein Befehl zu lange, zum Beispiel ein endloser Ping mit ping -t server, brichst du ihn mit Ctrl+C ab. Auf einer deutschen Tastatur heisst die Taste Strg.


    
Kopieren und einfügen

    
Ctrl+C hat zwei Rollen: Ist Text markiert, kopiert es ihn. Ist nichts markiert, bricht es ab. Einfügen geht mit Ctrl+V. Windows Terminal kennt zusätzlich Ctrl+Shift+C und Ctrl+Shift+V, die nie abbrechen.

    Schritt 5 · Mit Vorsicht
    
Wann «Als Administrator ausführen»?

    
Normalerweise arbeitet Lea mit ihren eigenen Rechten. Damit darf sie alles in ihrem Benutzerordner und kann fast alles anschauen. Für Änderungen am ganzen Computer braucht sie Adminrechte (Administratorrechte). Das ist wie der Generalschlüssel im Gemeindehaus: Man holt ihn nur, wenn man ihn wirklich braucht, und gibt ihn danach zurück.

    

      
Adminrechte nötig

        
    
          
  • Dienste starten oder stoppen (Station 12)
    • 
          
  • Programme für alle Benutzer installieren
    • 
          
  • Einstellungen für den ganzen Computer ändern
    • 
          
  • Dateien in geschützten Ordnern wie C:\Windows ändern
    • 
        

      
Geht ohne

        
    
          
  • Datum, Version und Ort anzeigen
    • 
          
  • Dateien im eigenen Benutzerordner anschauen und bearbeiten
    • 
          
  • Hilfe lesen und in pwsh 7 auch mit Update-Help aktualisieren
    • 
          
  • alles in diesem Lernpfad bis Station 11
    • 
        

    

    
Ohne Adminrechte scheitert ein solcher Befehl mit einer Fehlermeldung. So sieht es aus, wenn Lea den Dienst WolkenriedSync starten will:

    

    
Auf Deutsch: «Der Dienst kann nicht gestartet werden: Er lässt sich auf diesem Computer nicht öffnen.» Der Grund sind die fehlenden Rechte. Für eine Konsole mit Adminrechten klickst du im Startmenü mit der rechten Maustaste auf «PowerShell 7» und wählst Als Administrator ausführen. Windows fragt dann nach (Benutzerkontensteuerung). Meist steht danach «Administrator» im Fenstertitel.

    
Nicht immer als Administrator arbeiten. Mit Adminrechten führt PowerShell auch einen falschen Befehl ohne Widerspruch aus. Öffne die Admin-Konsole nur für die Aufgabe, die sie braucht, und schliesse sie danach.

    
Unterschied 5.1: In Windows PowerShell 5.1 braucht Update-Help Adminrechte. In 7 nicht mehr, dort speichert es die Hilfe im eigenen Benutzerordner.


    
Ausblick: PowerShell auf macOS und Linux

    
PowerShell 7 läuft auch auf macOS und Linux. Du startest sie dort ebenfalls mit pwsh, und die Cmdlets heissen gleich. Zwei Dinge sind anders: Pfade schreibt man mit / statt \, und unter Linux zählen bei Dateinamen Gross- und Kleinbuchstaben (Bericht.txt und bericht.txt sind zwei Dateien). Wie man PowerShell dort installiert, steht in den Anleitungen auf Microsoft Learn (Quellen unten).

    Schritt 9 · Selbst tippen
    
Tipp-Training

    
Lesen ist gut, Tippen ist besser. Hier schreibst du jeden Befehl selbst, Buchstabe für Buchstabe. Das Training hat drei Stufen: Erst tippst du ab, dann wandelst du einen Befehl ab, am Schluss findest du den Befehl allein. Jede Stufe hat ihre eigene Konsole. Tab und Pfeiltasten brauchst du nicht, es geht also auch auf dem Handy.

    
Verirrt? «↺ Zurücksetzen» stellt Leas Rechner wieder her. Gelöste Aufgaben bleiben gelöst. Gross und Klein ist bei Befehlsnamen egal, und für die meisten Aufgaben gibt es mehr als einen richtigen Weg.


    
Stufe 1 · Nachtippen

    
Der Befehl steht in der Aufgabe. Tippe ihn genau ab und drück Enter. So gewöhnen sich deine Finger an Bindestrich, Backslash und Anführungszeichen.

    


    
Stufe 2 · Abwandeln

    
Jetzt siehst du einen fertigen Befehl, brauchst aber etwas anderes. Ändere nur das, was sich ändern muss.

    


    
Stufe 3 · Selber lösen

    
Hier steht nur noch, was Lea wissen will. Den Befehl findest du selbst. Brauchst du einen Anstoss, öffne den Hinweis. Die Lösung kommt erst ganz zum Schluss.

    

  


  
  

    Lösungsfilm · Erst zuschauen, dann testen
    
Leas erster Auftrag: die Inventarliste

    
Lea hält fest, welche PowerShell auf ihrem Rechner läuft, wie der Rechner heisst und was in ihrem Benutzerordner liegt. Jede Szene zeigt die Eingabe und die Ausgabe.

    

    
Die Lösung als Text
      

        
1. Version: $PSVersionTable zeigt PSVersion 7.6.1 und PSEdition Core, also PowerShell 7. 2. Rechnername: hostname zeigt WR-LEA-01. 3. Ort: Get-Location zeigt C:\Users\lea. 4. Inhalt: Get-ChildItem zeigt die Ordner Berichte, Bilder, Dokumente, Downloads und Logs.

        
Leas Notiz: «WR-LEA-01: PowerShell 7.6.1 (Core). Benutzerordner C:\Users\lea mit Berichte, Bilder, Dokumente, Downloads, Logs.» Eigene Lösung, die Befehle in pwsh 7.6 nachgeprüft (Leas Rechner gibt es nur im Simulator).

      

    

  


  
  

    Typische Fehler
    
Sechs Stolpersteine

    
Den Prompt mitkopiert. In Anleitungen steht oft PS C:\Users\lea> Get-ChildItem. Kopierst du die ganze Zeile, liest PowerShell PS als Befehl. ps ist ein Kurzname für Get-Process, und so kommt eine unerwartete Meldung:
      
PS C:\Users\lea> PS C:\Users\lea> Get-ChildItem
Get-Process: A positional parameter cannot be found that accepts argument 'Get-ChildItem'.

      Kopiere nur den Teil nach >.

    
Bindestrich vergessen oder Leerzeichen eingebaut. GetDate und Get - Date kennt PowerShell nicht («is not recognized»). Verb und Nomen hängen ohne Leerzeichen mit einem Bindestrich zusammen: Get-Date.

    
Die falsche PowerShell geöffnet. Im Startmenü stehen «Windows PowerShell» (5.1) und «PowerShell 7» untereinander. Verhält sich ein Befehl anders als hier beschrieben, prüfe mit $PSVersionTable, ob PSEdition wirklich Core zeigt.

    
Ctrl+C kopiert nicht. Ohne markierten Text bricht Ctrl+C die Eingabe ab, statt zu kopieren. Erst markieren, dann kopieren. Oder in Windows Terminal Ctrl+Shift+C.

    
Lange Namen von Hand tippen. Wer Get-ChildItme tippt, bekommt «is not recognized». Mit Tab passiert das nicht: Tippe Get-Chi, Tab, fertig.

    
Immer als Administrator. Die Admin-Konsole ist bequem, weil nichts an fehlenden Rechten scheitert. Genau das ist gefährlich: Auch Fehler gehen dann ungebremst durch. Adminrechte nur, wenn eine Aufgabe sie verlangt.
